# Prototipo original

Este es el juego tal y como estaba antes de la reescritura: un único fichero HTML de
3.624 líneas con React y Babel cargados desde CDN y compilados en el navegador.

Se conserva solo como referencia histórica. **No es jugable tal cual**: la clave de API
que llevaba escrita en el código se ha eliminado de esta copia.

> ⚠️ La clave de Groq original estuvo visible en texto plano dentro de este fichero.
> Si es tuya, revócala en <https://console.groq.com/keys>.

El juego actual está en la raíz del repositorio. El README principal detalla qué se
corrigió y qué se añadió.
